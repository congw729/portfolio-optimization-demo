## 1. 当前 6 只资产的主题契合度分析（基线）

### 1.1 契合点（为什么当初选它）

| 契合点 | 说明 |
|---|---|
| 数据可得性与流动性 | 均为美股大盘蓝筹、市值前 20、上市 20 年以上，yfinance 数据完整稳定，无退市/停牌风险（准备清单 §2 的已知坑最小） |
| 行业分散（基本面） | 覆盖科技（4 只）、金融（JPM）、能源（XOM）三大板块，GMV 组合波动率可低于任一单资产，能演示「分散化降低风险」 |
| 教学叙事简单 | 学生认识这些公司，讲解代入感强；收益-风险对比度尚可 |

### 1.2 局限（教学视角：哪些主题维度覆盖不到）

| # | 局限 | 教学影响 |
|---|---|---|
| L1 | **4/6 为科技股，板块内相关性过高**（AAPL/MSFT/GOOGL/AMZN 两两相关普遍 0.7+） | 有效前沿偏窄、弯曲度小，「分散化收益」展示不充分；相关矩阵几乎全是高正值，**无法展示负相关/低相关资产的协方差结构** |
| L2 | **缺债券、缺商品、缺国际资产** | 无法演示「股债负相关」「商品对冲」「全球化分散」这些 portfolio optimization 教材里的经典案例；**资产配置（asset allocation）这一核心章节完全覆盖不到** |
| L3 | 个股特有风险干扰教学 | 单只股票受财报、行业事件等 idiosyncratic risk 影响大，与「组合风险 = 系统性风险」的教学主线有噪音 |
| L4 | 与「课程主题」定位偏差 | 课程若叫 Portfolio Optimization，主题重心在「如何配置资产类别」而非「如何选个股」；纯个股池更像 stock-picking demo |

**结论**：当前 6 只**不差，但「主题信息量」不足**——它只能讲清楚「分散化降风险」，讲不透「协方差结构多样性」「负相关资产的价值」「资产配置」。这正是用户质疑的合理之处。

### 方案 A：跨资产类别组合（股 + 债 + 商品 + 国际）—— ⭐ 推荐

**资产构成（6 只，全部美股上市 ETF）**：

| ticker | 名称 | 资产类别 | 在组合中的角色 |
|---|---|---|---|
| SPY | SPDR S&P 500 ETF | 美股大盘股 | 核心权益 |
| IWM | iShares Russell 2000 ETF | 美股小盘股 | 规模因子分散 |
| TLT | iShares 20+ Year Treasury Bond ETF | 美国长期国债 | **与股票负相关**，风险对冲 |
| GLD | SPDR Gold Shares | 黄金 | **与股债均低相关**，通胀对冲 |
| EEM | iShares MSCI Emerging Markets ETF | 新兴市场股票 | 国际分散 |
| DBC | Invesco DB Commodity Index ETF | 大宗商品 | 商品敞口、通胀对冲 |

**与主题契合度**：★★★★★（最高）
- 直接对应「资产配置」这一 portfolio optimization 的核心应用：股/债/商品/国际四大类别，是 Markowitz 框架的标准教学载体。
- 协方差结构**同时包含正相关（SPY↔IWM↔EEM）与负相关（SPY↔TLT）与近零相关（GLD↔其他）**，能完整讲透相关矩阵与分散化原理。
- 有效前沿形状典型（弯曲明显、GMV 与切线组合分离清晰），「风险-收益权衡」可视化效果好。

**教学演示亮点**：
1. 相关矩阵热力图出现**负相关元素**（股债），这是当前 6 只个股方案做不到的；
2. 可演示「60/40 组合 vs 全股票组合」风险对比，引出资产配置经典结论；
3. 有效前沿上债券/黄金如何「拉宽」可行域，直观展示分散化收益；
4. 可扩展到「通胀环境」「利率上行」等情景讨论（课程加分项）。

**数据可得性与现场稳健性**：★★★★★
- 全部为超大盘流动性 ETF（SPY/TLT/GLD 日均成交额数十亿美元），yfinance 数据完整、无退市风险；
- ETF 无个股财报/拆股事件噪音；`auto_adjust=True` 自动处理分红（ETF 分红对价格影响极小）。
- ⚠️ 需验证：DBC 跟踪商品期货指数，与现货商品有展期损耗（contango），5 年收益可能为负——这本身可作教学素材（「商品不是纯多头资产」），但需在演示前实测收益方向，避免学员困惑。

**取舍与代价**：
- 代价 1：DBC/TLT 近 5 年可能负收益，需在演示中解释「组合优化的目标是风险调整后收益，不是单资产正收益」；
- 代价 2：跨类别资产收益率量级差异大（股票 ~10% vs 债券 ~3%），需在讲均值-方差时强调「用年化均值」而非简单平均；
- 代价 3：相比个股，学生对公司熟悉度低——但课程主题是「配置」而非「选股」，可接受。

## 3. 推荐方案与理由

### 推荐：方案 A（跨资产类别组合：SPY / IWM / TLT / GLD / EEM / DBC）

**推荐理由**：

1. **主题契合度最高**：课程叫 Portfolio Optimization，其教科书核心章节是「资产配置」（asset allocation）——如何把资金分配到股/债/商品/国际。方案 A 是唯一完整覆盖这四大类别的方案，直接命中课程主线；方案 B/D 仍是纯权益、方案 C 缺商品。
2. **协方差结构教学信息量最大**：同时包含正相关（股↔股）、负相关（股↔债）、近零相关（黄金↔其他）三类关系，相关矩阵热力图是全场最有信息量的单张图；基线 6 只个股只能展示「全是正相关」。
3. **有效前沿形状最典型**：跨类别组合的可行域显著更宽，前沿弯曲明显，GMV 与切线组合分离清晰，「分散化收益」肉眼可见——这直接支撑验收标准 A2（GMV 波动率 ≤ 任一单资产）的演示效果。
4. **数据可得性与稳健性最好**：全部为超大盘 ETF，无个股特有风险（财报/退市/停牌），yfinance 数据完整；现场断网用缓存方案（准备清单 §2.4）即可兜底。
5. **扩展性最好**：可平滑扩展到风险平价（债券/黄金天然低风险贡献）、Black-Litterman（用 ETF 先验更合理）、以及课程加分讨论（60/40、通胀对冲、利率周期）。

**与基线对比（一句话）**：基线 6 只个股适合「选股型」叙事，方案 A 适合「配置型」叙事——后者与 Portfolio Optimization 课程定位一致；方案 A 保留基线作为对比组合（演示时可同时画两组前沿，展示「资产类别分散 vs 个股分散」的差异，反而成为亮点）。

## 5. 验证代码（方案 A 快速核验）

```python
# 环境：uv 虚拟环境（见 local-env-setup-uv.md），已装 yfinance
import yfinance as yf
import numpy as np
import pandas as pd

tickers = ["SPY", "IWM", "TLT", "GLD", "EEM", "DBC"]
data = yf.download(tickers, start="2021-01-01", end="2026-08-13",
                   group_by="ticker", auto_adjust=True, threads=True)
closes = data.loc[:, (slice(None), "Close")]; closes.columns = tickers
closes = closes.ffill().dropna(how="any")

returns = closes.pct_change().dropna()
ann_ret = returns.mean() * 252
ann_cov = returns.cov() * 252
corr = returns.corr()

print("年化收益:\n", ann_ret.round(4))
print("相关系数矩阵:\n", corr.round(2))
print("存在负相关:", (corr.values[np.triu_indices(len(tickers), 1)] < 0).any())
print("可用交易日数:", len(returns))
```

**预期输出特征**：`ann_ret` 中 SPY/IWM/EEM 为正、TLT/DBC 可能为负（⚠️ 需实测确认）；`corr` 中 SPY↔TLT 为负（约 -0.3~-0.5）；`可用交易日数` ≥ 1000；`存在负相关: True`。
